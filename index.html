Live hero, item, structure and APM data — none of it available to the other overlays out there.

MMR, league, division, season rank, match history, win probability and opponent scouting, pulled from the ladder API.

FAQ

What does the trial give me?

The first launch is a full-featured 6-minute trial — no feature is locked. After it ends you’ll need a license key. There’s no permanent free tier.

Why does it need an internet connection?

On startup w3eye fetches the current list of revoked license keys and a trusted server time. Both keep licensing honest and stop a stale key from running forever. Game data itself comes locally from shared memory.

Where does the data come from?

Match, hero, item and clock data is read from the game’s official War3StatsObserverSharedMemory — zero polling, instant. MMR, league, history and scouting come from the W3Champions REST API.

Does it work in observer / battle.net play?

Yes — anywhere the shared memory is present (in a game or in observation). That’s exactly what makes the instant, accurate data possible.
